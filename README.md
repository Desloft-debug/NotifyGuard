# Тихие уведомления (NotifyGuard)

Android 14 (targetSdk 34, minSdk 29), Kotlin + Jetpack Compose.

Скрывает рекламные уведомления, оставляет коды подтверждения, операции по счёту и экстренные сообщения. Отдельным переключателем приглушает звонки с номеров, которых нет в контактах.

## Сборка

Открыть папку в Android Studio (Ladybug или новее) и нажать Run. Из командной строки:

```
gradle wrapper          # один раз, если нет gradlew
./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

## Первый запуск

1. **Чтение уведомлений** — экран «Доступ» → «Открыть настройки» → включить «Тихие уведомления» в списке. Без этого фильтр не работает.
2. **Контакты** — разрешить доступ, иначе все номера считаются знакомыми и ничего не приглушается.
3. **Проверка звонков** — «Назначить», система спросит, сделать ли приложение приложением для проверки вызовов.

## Как принимается решение

Порядок проверок в `FilterRules.decide()`:

1. Системные пакеты (телефон, будильник, экстренные оповещения `cellbroadcast`) — не трогаем никогда.
2. Категории `CATEGORY_CALL`, `CATEGORY_ALARM`, `CATEGORY_EVENT`, `CATEGORY_REMINDER` и постоянные уведомления — пропускаем.
3. Слова экстренных оповещений (МЧС, evacuation, Unwetter, NINA) — пропускаем.
4. Чёрный список приложений — скрываем.
5. Белый список приложений — пропускаем.
6. Слова кодов и денег (код, OTP, TAN, перевод, зачислено, Überweisung, ₽, €) — пропускаем. Эта проверка идёт **до** рекламной, поэтому SMS вида «Код 1234. И скидка 20%» останется видимым.
7. Рекламные слова (скидка, промокод, Rabatt, sale) — скрываем.
8. Если ничего не совпало: в строгом режиме скрываем, в обычном пропускаем.

Списки слов лежат в `FilterRules.kt` — их можно править под свои банки и язык.

## Два уровня перехвата

- `GuardNotificationListener` снимает уведомление уже после публикации. Баннер может мигнуть на долю секунды.
- `GuardAssistantService` понижает важность **до** показа, поэтому баннера и звука нет вовсе. Работает, только если приложение выбрано ассистентом уведомлений в системных настройках. На большинстве серийных прошивок этот слот занят Android System Intelligence и менять его нельзя — тогда работает только первый слой. Это ограничение системы, обойти его без root нельзя.

## Про звонки

`GuardCallScreeningService` вызывает `setSilenceCall(true)` — рингтон и вибрация отключаются, но звонок не сбрасывается, остаётся в журнале вызовов и в пропущенных. Экстренные вызовы система через скрининг не проводит.

Роль проверки вызовов одна на устройство: пока её держит это приложение, другие определители номера работать не будут.

## Что стоит знать

- Приложение не читает SMS через `READ_SMS` — оно смотрит только текст уведомлений. Разрешение на чтение SMS Google Play выдаёт единицам, а для этой задачи оно не нужно.
- Уведомления никуда не отправляются, весь разбор идёт на устройстве, журнал хранится в `SharedPreferences`.
- Фильтр по словам ошибается на редких формулировках. Журнал «Что было скрыто» показывает каждое снятое уведомление с причиной — по нему удобно добавлять приложения в белый список.
- Банковское приложение лучше сразу занести в белый список, а его промо отключить внутри самого банка: так ни один перевод точно не потеряется.
